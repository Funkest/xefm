# 文字エンコーディング

[English](TEXT_ENCODING_FEATURE.md) \| 日本語

テキストビューアーはファイルの文字エンコーディングを自動で判定します。そのため、Shift-JIS、EUC-JP、ISO-2022-JP といった従来の日本語テキストも、BOM の有無にかかわらず UTF-8 と並んで正しく表示されます。判定を誤ったファイルは、ビューアーの中からエンコーディングを明示的に選べます。

## 自動判定

テキストビューアー（`view_file`）でファイルを開くだけで、次のエンコーディングが正しく表示されます。

- **UTF-8** — BOM の有無を問いません（BOM が余計な文字として表示されることはありません）
- **UTF-16 / UTF-32** — ファイルが BOM で始まる場合（どちらのバイト順でも）
- **Shift-JIS (CP932)** — Windows の日本語エンコーディング
- **EUC-JP** — 昔からの Unix の日本語エンコーディング
- **ISO-2022-JP** — 古い日本語メールでよく使われた 7 ビットのエンコーディング
- **CP1252 / Latin-1** — 西欧の 1 バイトテキスト

ヘッダーの右側には使用中のエンコーディングが表示される（例：`Shift-JIS  12/340`）ので、判定が何を選んだかが常にわかります。判定は内容に基づいて行われ、拡張子の一覧やロケールからの推測は使いません。また、必ず何かが表示されます。どれにも当てはまらないファイルは、開くのを拒否する代わりに Latin-1 として表示されます。

同じ判定は差分ビューアーでも使われるので、2 つの Shift-JIS ファイルを比較すると、両側に本来のテキストが表示されます。内容検索（`find_in_files`）も BOM を尊重します。UTF-16/32 のファイルはバイナリとして飛ばされずにテキストとして検索され、UTF-8 の BOM が 1 行目での `^` で始まるマッチを妨げることもありません。

## エンコーディングを手動で選ぶ

ビューアーで `change_encoding` を実行すると、エンコーディングの選択ダイアログが開きます。

- **Auto** — 既定値です。この行には判定が選んだエンコーディングも表示されるので、選択ダイアログはそのまま表示器の役も果たします。
- 設定の `TEXT_ENCODINGS` リスト（後述）にあるエンコーディングごとに 1 行。

`↑`/`↓` で選びます。入力を始めることもできます（`s` で Shift-JIS へ、`eu` で EUC-JP へ移動し、一致したものがダイアログの下部に表示されます）。`Enter` で適用し（ファイルはスクロール位置を保ったままその場でデコードし直されます）、`Esc` でキャンセルします。選択は、現在有効になっているものの上で開きます。

ビューアーの中では、`edit_file` もファイル一覧と同じキーで使えます（そのキーはキーマッププリセットによって異なります。[キーマッププリセット](KEYMAP_PRESETS_FEATURE.ja.md#すべてのキーの一覧)を参照してください）。ファイル一覧から使うときとまったく同じように、表示中のファイルを設定したエディターで開きます。ターミナルのエディターから戻ると、ビューアーはファイルを読み込み直します。

手動で選んだ場合も、常に *何か* が表示されます。選んだエンコーディングで表せないバイトは、拒否されずに置換文字（`�`）として表示されます。**Auto** を選ぶと自動判定に戻ります。

手動指定が役に立つのは次の 2 つの場合です。

- **判定が誤ったとき。** 短いファイルや変わったバイトの組み合わせは、どんな判定器でも誤ることがあります。正しいエンコーディングを選べば、すぐに表示が直ります。
- **BOM のない UTF-16。** BOM がないと、UTF-16 のファイルはバイナリデータと区別できません（ASCII 文字のどれもが NUL バイトを含むため）。そのため、ビューアーはバイナリ用の代替表示を出します。`utf-16-le` を強制すれば（`TEXT_ENCODINGS` に追加してください）、テキストとして表示されます。

この選択はファイルごと・表示ごとです。ビューアーを閉じると忘れられ、ファイルを開き直すと改めて判定されます。

## 選択ダイアログの設定

選択ダイアログのエンコーディング一覧は `~/.xefm/config.py` にあります。

```python
TEXT_ENCODINGS = ['utf-8', 'cp932', 'euc-jp', 'iso-2022-jp', 'latin-1']
```

[Python のコーデック名](https://docs.python.org/3/library/codecs.html#standard-encodings)であれば何でも使えます。`'koi8-r'`、`'gb2312'`、`'utf-16-le'` など、扱うものを何でも追加してください。この一覧は手動の選択ダイアログにだけ使われます。自動判定は組み込みで、この一覧の影響を受けません。

キーは、ほかのアクションと同じく `KEY_BINDINGS['change_encoding']` で割り当て直せます（[キーバインド](KEY_BINDINGS_FEATURE.ja.md)を参照）。
