# マウス

[English](MOUSE_EVENT_SUPPORT_FEATURE.md) \| 日本語

XeFM はキーボードで素早く操作できるように作られていますが、マウスも一緒に使えます。ファイルのマークや開く操作、ドラッグでの移動、スクロールやジャンプを、すべてマウスで行えます。マウスの操作にはどれも対応するキーがあります。

## 使える環境

| | デスクトップアプリ（macOS、Windows） | ターミナル |
|---|---|---|
| クリック、ダブルクリック、右クリック、ホイール | 可 | 可（マウスを報告するターミナルで） |
| Cmd/Ctrl-クリック、Shift-クリック | 可 | Ctrl-クリックはたいてい可。Shift-クリックはターミナルが渡す場合のみ（後述） |
| 中クリック、戻る／進むボタン | 可 | ターミナルが報告する場合 |
| ファイルをほかのアプリへドラッグして出す | 可 | 不可 — 代わりにパスがクリップボードにコピーされます |
| ほかのアプリからファイルをドロップして入れる | 可 | 不可 |

デスクトップアプリは `xefm --backend gui` で起動します。既定はターミナルです。

## ファイル一覧でのクリック

XeFM は 2 つのものを区別しています。1 つの行にある **カーソル** と、いくつの行にでも付けられる **マーク** です。操作はマークしたファイルに対して、何もマークしていなければカーソル位置のファイルに対して働きます。マウスもこの同じモデルに従います。

| 操作 | 動作 |
|---|---|
| クリック | カーソルをそこへ移動し、そのペインをアクティブにします。マークはそのままです。 |
| Cmd-クリック（macOS）／ Ctrl-クリック | カーソルを移動し、その行のマークを付け外しします。 |
| Shift-クリック | 最後にクリックした行からこの行までのすべての行をマークし、既存のマークに加えます。 |
| ダブルクリック | Enter と同じく行を開きます。フォルダーやアーカイブに入り、ファイルを開きます。 |
| フォルダー上で中クリック | そのフォルダーを反対側のペインで開きます。 |
| 右クリック | その行のコンテキストメニューを開きます。最後の行より下では、ディレクトリのメニューを開きます。 |
| 最後の行より下をクリック | カーソルを動かさずにペインをアクティブにします。 |

マークを付けるのには手間がかかることが多いので、普通のクリックでマークが消えることはありません。マークを消すには **Select ▸ Unselect All** かコンテキストメニューを使ってください。

macOS では、どの Mac アプリとも同じく **Control-クリック** が副ボタンのクリックで、コンテキストメニューを開きます。マークには **Command**-クリックを使ってください。

**ターミナルでは**、ほとんどのターミナルで Ctrl-クリックが使えます。多くのターミナルは Shift-クリックを自身のテキスト選択に使い、アプリに渡しません。Shift-クリックが届かない場合は、代わりに Space とコンテキストメニューの Select / Deselect を使ってください。

## スクロール

- **ホイールまたはトラックパッド**：どちらのペインがアクティブでも、ポインターの下にあるペインをスクロールします。カーソルは動きません。
- **スクロールバー**：つまみをドラッグするか、その上下をクリックして 1 ページ移動します。

## 一覧の周りのバー

- **ペインの上のパス** はリンクの並びとして働きます。その中のフォルダー名をクリックするとそのフォルダーへ移動し、カーソルは元いたフォルダーの上に置かれます。アーカイブの中や SSH、S3 でも、Backspace と同じ手順で上へたどって動作します。
- **ペインのフッター**：ソートの説明をクリックするとソートメニューが開き、フィルターをクリックするとフィルターを変更できます。
- **ウィンドウ下部のキーのヒント**：クリックするとそのキーの操作を実行します。ヒントには自分のキーバインドが表示されるので、常にキーマップと一致しています。

## 戻る・進む

各ペインは表示したフォルダーを覚えています。ブラウザーのように戻ったり進んだりできます。

| | キー | マウス |
|---|---|---|
| 戻る | `Alt-←`（macOS アプリでは `Cmd-[` も） | 戻るボタン |
| 進む | `Alt-→`（macOS アプリでは `Cmd-]` も） | 進むボタン |

これは、親フォルダーへ移動する Backspace とも、最近使ったフォルダーを一覧する **H** とも異なります。同じコマンドは **Go** メニューにもあります。

## ファイルのドラッグ

### XeFM から外へ

行の上でボタンを押してドラッグします。その行がマークされていれば、マークしたすべてのファイルが一緒に運ばれます。そうでなければその 1 つのファイルだけです。ファイルは Finder、エクスプローラー、ほかのアプリ、あるいは XeFM の反対側のペインにドロップします。背面にある XeFM ウィンドウからも、先に前面へ出さずにドラッグを始められます。

ドラッグできるのはローカルのファイルだけです。SSH や S3 上、あるいはアーカイブの中のファイルには、ほかのアプリに渡せるディスク上のファイルがありません。

### XeFM の中へ、またペインの間で

ペインにファイルをドロップすると、そのペインのフォルダーに入ります。フォルダーの行にドロップすると、そのフォルダーに入ります。何が起きるかは、システムの通常の規則に従います。

| | macOS | Windows |
|---|---|---|
| キーを押さない | ファイルが同じドライブにあれば移動、そうでなければコピー | 同じ |
| コピー | **Option** を押したまま | **Ctrl** を押したまま |
| 移動 | **Command** を押したまま | **Shift** を押したまま |

ドラッグ中は、カーソルにコピーか移動かが表示されます。ドロップは通常のコピーや移動として処理され、確認や、すでに存在するファイルのためのダイアログもそのまま表示されます。リンク（エイリアスやショートカット）を求めるドロップは拒否されます。

## ターミナルでは

ターミナルは、マウスの報告がオンになっている間だけマウスを報告します。XeFM はこれをオンにしますが、環境によってはそれを許可する設定も必要です。たとえば tmux では `set -g mouse on` が必要です。ターミナルが何も報告しない場合でも、すべての操作はキーボードで行えます。

## すべての操作にキーがあります

| マウス | キー |
|---|---|
| 行をクリック | 矢印キー |
| Cmd/Ctrl-クリック | Space（マークして下へ移動） |
| Shift-クリック | Shift-Space、または移動しながら Space |
| ダブルクリック | Enter |
| パスの中のフォルダーをクリック | Backspace（1 階層）、J / H（お気に入り、履歴） |
| 戻る／進むボタン | Alt-← / Alt-→ |
| スクロールバー | Page Up / Page Down、Home / End |
| ペイン間でドラッグ | `C`（コピー）/ `M`（移動） |
