# クイックビュー

[English](QUICK_VIEW_FEATURE.md) \| 日本語

**View → Quick View**（`quick_view`）を実行すると、**反対側のペインが、カーソル位置の項目のプレビューになります**。カーソルを動かすとプレビューもついてきます。もう一度実行するか、`Esc` を押すと閉じます。キーはキーマッププリセットによって異なります。[キーマッププリセット](KEYMAP_PRESETS_FEATURE.ja.md#すべてのキーの一覧)を参照してください。

| カーソル位置の項目 | プレビューの表示内容 |
|-----------------------|-------------------|
| テキストファイル | ファイルの先頭部分（最大 256 KB）。テキストビューアーと同じようにシンタックスハイライトされます |
| 画像 | ペインに合わせて縮小した画像 |
| そのほかのバイナリファイル | 先頭 512 バイトの 16 進ダンプ |
| フォルダー | 含まれるファイルとフォルダーの数と合計サイズ。見ている間に数えます |

内容の上のヘッダー行には、項目の名前とサイズ、日付が表示されます。

## 使い方

- **キーボードはファイル一覧に残ります。** いつもどおり移動、選択、フォルダーを開く、削除などができます。プレビューは見ているだけで、開いたフォルダーの中にもカーソルについていきます。
- **プレビューはマウスホイールでスクロールできます。**
- **反対側のペインは保たれます。** そのフォルダー、カーソル、選択は、クイックビューを閉じたときに元のとおりに戻ります。
- **ペインを切り替えると（`Tab`）クイックビューは閉じます。** プレビューは操作できるペインではありません。
- **クイックビューを開いている間は、反対側のペインへのコピーや移動は拒否されます。** そのペインのフォルダーはプレビューの裏に隠れているので、ファイルが見えない場所に置かれてしまうからです。反対側のペインとの比較や、2 つのペインのフォルダーの同期も同様です。先にクイックビューを閉じてください。ログにもその旨が表示されます。

## 速度

プレビューはカーソルが少し止まるまで待つので、長い一覧を素早く下へ移動しても、通り過ぎたファイルを一つ一つ読み込むことはありません。

**リモート** の場所（`ssh://`、`s3://`、アーカイブの中）では、256 KB までのファイルだけを読み込みます。それより大きなファイルはサイズと日付だけが表示されます。リモートのフォルダーは数えません。数えるにはネットワーク越しにツリー全体をたどることになるからです。

画像を描画できないターミナルでは、画像はその詳細だけが表示されます。
