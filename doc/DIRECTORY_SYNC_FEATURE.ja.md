# ディレクトリ同期

[English](DIRECTORY_SYNC_FEATURE.md) \| 日本語

[ディレクトリ差分](DIFF_VIEWER_FEATURE.ja.md#ディレクトリ差分)（`Shift+=`）では、項目を 1 つずつコピー・移動・削除できます。同期は残りを一度に片付けます。反対側をアクティブな側と同じ状態にするのです。何かが書き込まれる前に、計画の全体を確認できます。

## 同期の実行

1. `Shift+=` でディレクトリ差分を開き、比較が終わるのを待ちます。
2. コピー**元**にしたい側をアクティブな側にします。`Tab` で側を切り替えられ、アクティブな側のヘッダーが強調表示されます。
3. `s` を押してモードを選びます。

   | モード | 新しいファイルと変更されたファイル | 反対側にしかない項目 |
   |------|-----------------------|------------------------------|
   | **Update** | コピーする | 残す |
   | **Mirror** | コピーする | 削除する |

4. ビューアーに**計画**が表示されます。同一の項目は隠され、中央の列に残りの各項目がどうなるかが示されます。

   | 記号 | 意味 |
   |------|---------|
   | `→` / `←` | その方向にコピー |
   | `×` | 矢印の指す側で削除 |
   | `·` | そのまま |

   両側に存在するディレクトリには、それ自体の記号は付きません。展開すると中で何が起こるかが見られます。

5. 納得できない部分を変更し（下記参照）、もう一度 `s` を押します。コピー、置き換え、逆方向へのコピー、削除がそれぞれ何件になるかの概要が表示されます。**Sync** を選ぶと実行されます。

`Esc` を押すと何もせずに計画から抜け、比較はそのまま開いています。

## 計画の変更

項目の上で `Space` を押すと、その項目の動作が次のものに切り替わります。

- **新しい項目**：コピーするか、そのままにします。
- **変更されたファイル**：コピーするか、そのままにするか、逆方向へ**コピーし戻し**ます。これにより、両側にそれぞれ相手が必要とするファイルがいくつかあるフォルダーも、1 回の同期で処理できます。
- **反対側にしかない項目**：削除するか、そのままにするか、コピーし戻します。Update では「そのまま」、Mirror では「削除」から始まります。
- **両側にあるディレクトリ**：中身ごとスキップするか、項目ごとに決めます（既定）。

計画を開いている間も、`Enter` でファイル比較が、`E` でマージツールが開きます。マージしたあとは比較が更新され、その項目の動作が改めて決め直されます。ほかの変更はそのまま残ります。

`Tab` を押すと計画の方向が反転し、変更はリセットされます。

## 既定では同期が行わないこと

- **新しいファイルの上書き。** コピー先のほうが新しい変更済みファイルは「そのまま」から始まります。それでもコピーするには `Space` を押してください。こうしてそのままにされた件数は概要に表示されます。
- **ファイルをフォルダーで、またはフォルダーをファイルで置き換えること。** ある名前が一方ではファイル、もう一方ではフォルダーの場合、比較ではそれが相違（`!`、スラッシュはフォルダーの側にだけ付きます）として示され、同期では常にそのままにされます。
- **確認を重ねずに完全に削除すること。** 概要では削除がコピーとは分けて表示されます。完全に削除されるものがある場合、ダイアログは **Cancel** が選ばれた状態で開きます。

## 知っておきたいこと

- **削除したものはゴミ箱に入ります**（Windows ではごみ箱）。ゴミ箱がある場所ではどこでもそうなので、Mirror で削除したものも元に戻せます。ゴミ箱がない場所（`ssh://`、`s3://`、Windows のリムーバブルドライブやネットワークドライブ）では完全に削除され、概要にもそう示されます。`config.py` で `DELETE_TO_TRASH = False` とすると、すべて完全な削除になります。
- **コピーは削除より先に行われます。** 同期を途中でキャンセルすると（進捗ダイアログで `Esc`）、その時点で止まりますが、削除されたものはすべてのコピーが終わったあとで削除されています。済んだことは済んだまま残ります。
- **ファイルは内容で比較されます。** 「変更された」とは、日付だけでなくバイト列が異なるという意味です。
- **隠しファイルはビューアーの表示に従います。** 隠しファイルを表示していないときは比較されず、計画でもそのままにされます。フォルダーを丸ごとコピーまたは削除する場合は、隠しファイルを含めて中身すべてが対象になります。
- 同期は `C` や `K` と同じエンジンで、同じ進捗ダイアログとともに実行されます。ローカルフォルダー、`ssh://`、`s3://`、マウントした共有の間で使えます。

## キー

| キー | 動作 |
|-----|--------|
| `s` | 計画を開く、または開いている計画を実行する（`dir_diff.sync`） |
| `Space` | フォーカスのある項目の動作を変更する（`dir_diff.cycle_sync_action`） |
| `d` | 両側で同じ項目の表示／非表示を切り替える（`dir_diff.toggle_identical`） |
| `Esc` | 計画から抜ける |

どれも `KEY_BINDINGS` で割り当てを変更できます。[キーバインド](KEY_BINDINGS_FEATURE.ja.md)を参照してください。
