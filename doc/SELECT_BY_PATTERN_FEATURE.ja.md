# パターンで選択

[English](SELECT_BY_PATTERN_FEATURE.md) \| 日本語

ペインを先に絞り込まなくても、多くのファイルを一度に選択できる 3 つの方法です。

| アクション | キー | メニュー | 動作 |
|--------|-----|------|--------------|
| `select_by_pattern` | `'` | Select → Select by Pattern… | パターンを尋ね、一致するファイルをすべて選択に加えます |
| `unselect_by_pattern` | `"` | Select → Unselect by Pattern… | パターンを尋ね、一致するファイルをすべて選択から外します |
| `select_same_extension` | — | Select → Select Same Extension | カーソル位置のファイルと同じ拡張子のファイルをすべて選択に加えます |

3 つともコマンドパレット（`Ctrl-T`）からも実行できます。2 つのパターン用のキーは **Filter** の `;` と `:` の隣にあります。パターンは同じで、キーが 1 つずれているだけです。`select_same_extension` にはキーが割り当てられていません。[キー](#キー)を参照してください。

## パターン

パターンの書き方は **Filter**（`;`）とまったく同じです。

- ワイルドカードのパターン：`*.jpg`、`report_202?.*`、`[ab]*`。
- スペース（または `;`）で区切って複数指定：`*.jpg *.png *.gif`。どれか 1 つに一致すれば対象になります。
- スペースを含むパターンは引用符で囲みます：`"my file*"`。
- `config.py` の `FILTERS` で定義したフィルターの名前。たとえば `images` や、サイズでファイルを選ぶフィルターなら `big` などです。[カスタマイズ](CUSTOMIZATION_FEATURE.ja.md)を参照してください。

大文字と小文字は区別しません。`*.jpg` は `IMG_0001.JPG` も選びます。**Filter** で一部のファイルを表示するパターンは、ここでも同じファイルを選択します。検索結果のペインでも同じで、そこではファイル名が検索ルートからのパスなので、`sub/*` は `sub` の下のヒットを選択します。

入力欄には、定義済みのフィルターと以前に使ったパターンが一覧表示されます。この履歴は **Filter** と共通で、どちらかで入力したパターンは両方で候補に出ます。

## 選択される対象

- ファイルだけです。ディレクトリは、名前が一致する `*` のようなパターンであっても、パターンで選択されたり選択を外されたりすることはありません。ディレクトリには `toggle_select_items`（`Shift-A`）を使ってください。
- **Select** は加えるだけ、**Unselect** は外すだけです。それ以外の項目は選択状態がそのまま残るので、複数のパターンを続けて使うと積み重なります。`*.jpg` を選択し、次に `*.png`、それから `thumb_*` の選択を外す、といった使い方ができます。
- 何個のファイルが変わったか、あるいは何も一致しなかったことがログに表示されます。

## 同じ拡張子を選択

ファイルにカーソルを置いて `select_same_extension` を実行すると、ペイン内で同じ拡張子を持つファイルが大文字・小文字を問わずすべて選択されます。`photo.JPG` の上なら `.jpg` と `.JPG` をすべて選びます。拡張子のないファイル（`README`、`.bashrc`）の上では、拡張子のないほかのファイルを選択します。ディレクトリの上では何もしません。

## キー

`'` と `"` は文字なので、キーボード配列にかかわらず、デスクトップアプリでもどのターミナルでも同じように動作します。その文字を入力するキーを押してください（日本語キーボードでは `Shift-7` と `Shift-2`）。

Total Commander ではこれらが `Num+`、`Num−`、`Alt+Num+` に割り当てられています。XeFM はテンキーとメインのキーを区別できず、また `+` と `-` はすでにディレクトリの比較とペイン分割のリセットに使われています。キーを変更したり、`select_same_extension` にキーを割り当てたりするには、`config.py` で設定します。

```python
KEY_BINDINGS = {
    'select_by_pattern': ["'"],
    'unselect_by_pattern': ['"'],
    'select_same_extension': ['Y'],
}
```

キーの名前は[キーバインド](KEY_BINDINGS_FEATURE.ja.md)を参照してください。
