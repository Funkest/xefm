# ファイルパスの TAB 補完

[English](TAB_COMPLETION_FEATURE.md) \| 日本語

## 概要

XeFM のテキスト入力欄では、入力中にファイルやディレクトリのパスを補完できます。パスや名前を入力する欄で **TAB** を押すと、名前の残りが埋まるか、候補が複数ある場合は一致するエントリのリストがポップアップします。シェルのパス補完と同じように、1 回目の TAB で曖昧でない部分までが埋まり、2 回目の TAB（または入力の続き）で候補が表示されて絞り込まれます。

## 使える場所

| 入力欄 | 開き方 | 補完対象 |
|--------|-----------|-----------|
| **Jump to Path** | `jump_to_path` | ファイル + ディレクトリ |
| **New Directory** | create-directory | ファイル + ディレクトリ |
| **New File** | create-file | ファイル + ディレクトリ |
| **Rename** | `R`（単一の項目） | ファイル + ディレクトリ |
| **Create Archive** | create-archive | ファイル + ディレクトリ |

「Jump to Path」はディレクトリだけでなくファイルも補完します。この入力欄ではファイルのパスも有効な移動先で、ペインはそのディレクトリへ移動し、カーソルはそのファイルの上に置かれます。名前を付ける入力欄も両方を補完するので、`sub/dir/name` のように入れ子になった名前を入力するときに便利です。

## 使い方

1. パスや名前を入力し始めて **TAB** を押します。
2. **一致が 1 つの場合** — 完全に埋められます。ディレクトリには末尾に `/` が付くので、もう一度 TAB を押すとその中へ進めます。
3. **一致が複数の場合** — 共通する先頭部分が埋められ、入力欄のすぐ下に**候補リスト**が表示されます。
   - そのまま**入力**を続けるとリストが絞り込まれます（リアルタイムに更新され、一致するものがなくなると隠れ、一致が 1 つだけ残っても表示されたままです）。
   - **↑ / ↓**（PageUp / PageDown も）でリスト内のハイライトを移動します。端まで行くと反対側に戻ります。
   - ハイライトされた行で **Enter** を押すと、そのエントリが挿入されます。どの行もハイライトされて**いない**ときは、Enter はいつもどおり入力欄の内容を確定します。そのため、入力したものをそのまま確定したいときに補完が邪魔になることはありません。
   - 行を**クリック**すると、その行が挿入されます。
   - **Esc** でリストを閉じます（もう一度 Esc を押すと入力欄をキャンセルします）。

`~`（ホームディレクトリ）で始まるパス、相対パス、絶対パスのいずれも補完できます。マッチングは、ファイルシステムの名前の扱いに合わせて**大文字と小文字を区別**します。

## 隠しファイル

補完はペインの**隠しファイルの表示切り替え**に従います。隠しファイルを表示しない設定の間は、ドットで始まるエントリ（`.config`、`.gitignore`、…）は候補に現れません。ファイルリストと同じ規則です。

シェルと同じく、先頭のドットを自分で入力すると、そのトークンに限ってこの規則が解除されます。隠しファイルを表示しない設定でも `.c` + TAB で `.config/` が補完されるので、表示を切り替えなくても隠しディレクトリにたどり着けます。

Windows では、名前ではなく属性によってエントリが隠されていることがあります（`AppData`、`$Recycle.Bin`）。これらも表示切り替えに従いますが、入力するべき先頭のドットがないので、何を入力してもそのトークンに限って表示させることはできません。たどり着くには隠しファイルの表示を有効にしてください。

## 注意事項と制限

- 補完は**リモートの場所**でも使えます。SSH や S3 のペイン、アーカイブの中、Jump to Path に入力した `ssh://host/srv/` のようなパスでも動作します。リモートのパスは常に `/` を使います。アーカイブの中では `#` の後ろの部分も補完されます。ホスト名やバケット名を入力し終えるまでは何も問い合わせないので、`ssh://ho` の時点ではまだ何も候補が出ません。接続できないホストでも、エラーにはならず何も候補が出ないだけです。
- 候補の元になるディレクトリの一覧は **1 回の走査**で読み取られ（ファイルペインと同じ高速な列挙方法です）、**バックグラウンド**で実行されます。遅い場所（ネットワークマウントや、回転が止まったディスク）でも入力欄はキー入力を受け付け続け、一覧が届いた時点で候補が表示されます。ローカルディスクでは即座に表示されるのと区別がつきません。
- まだ存在しないパスを補完しようとしても害はありません。TAB を押しても何も候補が出ないだけです。
