# 検索中のアニメーション

[English](SEARCH_ANIMATION_FEATURE.md) \| 日本語

## 概要

XeFM は、ファイルの検索のように時間のかかる操作の間、アニメーションする進捗インジケーターを表示します。このアニメーションで、XeFM が処理中であることがわかり、操作中の視覚的なフィードバックが得られます。

## アニメーションのスタイル

いくつかのアニメーションのスタイルから選べます。

1. **Spinner** - 定番の回転するインジケーター（既定）
   - 表示：`⠋ ⠙ ⠹ ⠸ ⠼ ⠴ ⠦ ⠧ ⠇ ⠏`
   - 一般的な用途に最適

2. **Dots** - ミニマルな点のアニメーション
   - 表示：`⠁ ⠂ ⠄ ⡀ ⢀ ⠠ ⠐ ⠈`
   - 気が散りにくい環境に向いています

3. **Progress** - プログレスバー風
   - 表示：`▏ ▎ ▍ ▌ ▋ ▊ ▉ █`
   - 動作中であることを視覚的に表します

4. **Bounce** - シンプルに跳ねる点
   - 表示：`⠁ ⠂ ⠄ ⠂`
   - 控えめでリズミカル

5. **Pulse** - 脈打つ円
   - 表示：`● ◐ ◑ ◒ ◓ ◔ ◕ ○`
   - 落ち着いていて滑らか

6. **Wave** - 波のようなバー
   - 表示：`▁ ▂ ▃ ▄ ▅ ▆ ▇ █ ▇ ▆ ▅ ▄ ▃ ▂`
   - 動きがあって目を引きます

7. **Clock** - 時計の文字盤のアニメーション
   - 表示：`🕐 🕑 🕒 🕓 🕔 🕕 🕖 🕗 🕘 🕙 🕚 🕛`
   - 進行がはっきりわかります

8. **Arrow** - 回転する矢印
   - 表示：`← ↖ ↑ ↗ → ↘ ↓ ↙`
   - 動きがはっきりわかります

## 設定

XeFM の設定ファイル（`~/.xefm/config.py`）に次の設定項目を追加します。

```python
class Config(DefaultConfig):
    # Choose your animation style
    PROGRESS_ANIMATION_PATTERN = 'spinner'  # Default: 'spinner'
    PROGRESS_ANIMATION_SPEED = 0.2          # Default: 0.2 seconds
```

### 設定項目

- **PROGRESS_ANIMATION_PATTERN**：アニメーションのスタイルを選びます
  - 選択肢：`'spinner'`、`'dots'`、`'progress'`、`'bounce'`、`'pulse'`、`'wave'`、`'clock'`、`'arrow'`
  - 既定値：`'spinner'`

- **PROGRESS_ANIMATION_SPEED**：アニメーションの速さ
  - 既定値：フレームの間隔 `0.2` 秒
  - 小さい数値ほど速いアニメーション
  - 大きい数値ほど遅いアニメーション
  - 推奨：`0.1` ～ `0.5`

## 動作のしくみ

アニメーションは、検索のような操作の間、自動的に表示されます。何もする必要はありません。検索を始めればアニメーションが表示されます。

### 表示の例

**Spinner のアニメーション：**
```
Searching ⠋ (15 found)
Searching ⠙ (28 found)
Searching ⠹ (42 found)
```

**Dots のアニメーション：**
```
Searching ⠁ (15 found)
Searching ⠂ (28 found)
Searching ⠄ (42 found)
```

**Progress のアニメーション：**
```
Searching [█░░░░░░░] (15 found)
Searching [██░░░░░░] (28 found)
Searching [███░░░░░] (42 found)
```

## アニメーションが表示される場面

- **ファイル名検索**：名前でファイルを検索するとき
- **内容検索**：ファイルの中を検索するとき
- **時間のかかる操作**：時間がかかるあらゆる操作の間

## 検索結果の上限

大きなディレクトリツリーでも性能が予測できるように、検索結果には内部で上限が設けられています（大きな上限に達するとスキャンが止まります）。上限に達すると検索は止まり、状態表示に「limit reached」と表示されます。これがよく起きる場合は、より具体的な検索パターンを使ってください。

## トラブルシューティング

### アニメーションが表示されない
- ターミナルが Unicode の文字に対応しているか確認してください
- 別のアニメーションのパターンを試してください（spinner が最もよく動作します）
- アニメーションの速さが遅すぎないか確認してください

### アニメーションが速すぎる、または遅すぎる
- `PROGRESS_ANIMATION_SPEED` の設定項目を調整してください
- 0.1（速い）～ 0.5（遅い）の値を試してください

### 文字が正しく表示されない
- ターミナルによっては、すべての Unicode の文字には対応していません
- 'spinner' のパターンを試してください。最も互換性が高いパターンです
- 最新のターミナルへの乗り換えを検討してください

## ヒント

- 'spinner' のパターンはほとんどのターミナルで動作します
- 遅めの速さ（0.3-0.5）は目に優しくなります
- 速めの速さ（0.1-0.2）は反応がよく感じられます
- アニメーションは検索の速さや性能には影響しません
