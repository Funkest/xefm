# フラット表示

[English](FLAT_VIEW_FEATURE.md) \| 日本語

フラット表示は、ペインの一覧を **現在のディレクトリ以下のすべてのファイル** を並べた 1 つの平坦なリストに切り替えます。もう一度実行すると元に戻ります。

| アクション | メニュー |
|--------|------|
| `flat_view` | View → Flat View |

キーはキーマッププリセットによって異なります。[キーマッププリセット](KEYMAP_PRESETS_FEATURE.ja.md#すべてのキーの一覧)を参照してください。コマンドパレット（**Tools → Command Palette…**）からも実行できます。

```
Photos/                          2024/trip/a.jpg
  2024/trip/a.jpg       →        2024/trip/b.jpg
  2024/trip/b.jpg                2025/c.jpg
  2025/c.jpg                     notes.txt
  notes.txt
```

## 用途

一覧に対してできることは、何でもツリー全体に一度に使えます。

- **容量を使っているものを探す** — サイズでソートします（**View → Sort By → Size**）。
- **最近変わったものを見る** — 日付でソートします（**View → Sort By → Date**）。
- **同じ種類のファイルを集める** — `*.jpg` で絞り込み（**View → Filter…**）、すべて選択して反対側のペインにコピーします。

表示、編集、名前の変更、削除、比較、詳細の表示もいつもどおりに行えます。

## 一覧に含まれるもの

- **ファイルだけです。** ディレクトリ自体は行になりませんが、その中のファイルはすべて一覧に入ります。
- 各行の名前は、開始したディレクトリからのパスになります（`2024/trip/a.jpg` など）。ソート、フィルター、インクリメンタルサーチはこのパスを使うので、`2024/*` で 1 年分に絞り込めます。
- **隠しファイルはペインの設定に従います。** ペインが隠しているもの（**View → Show Hidden Files** で切り替え）は一覧に入らず、その中も調べません。
- **ディレクトリへのシンボリックリンクはたどりません。** そのため、ツリーの上の階層を指すリンクがあっても一覧が無限に続くことはありません。ファイルへのリンクは一覧に入ります。
- ペインのヘッダーは `[Flat view] /the/directory` と表示されます。

## ツリーの一部だけを平坦化する

フラット表示にしたときに項目が選択されていれば、それらだけが平坦化されます。選択したディレクトリはその下のすべてを、選択したファイルはそのファイル自身を一覧に加えます。ディレクトリ全体を平坦化するには、先に選択を解除してください（**Select → Clear Selection**）。

## 大きなツリーとリモートのツリー

進捗ダイアログは見つかったファイルを数えながら表示し、`Esc` で走査を止められます。止めた場合は、ツリーの一部を表示するのではなく、ペインが元の状態のまま残ります。フラット表示はほかの場所と同じく、`ssh://` や `s3://` の下、アーカイブの中でも使えます。

## 元に戻る

もう一度 **View → Flat View** を実行するか `Backspace` を押すと、元のディレクトリに戻り、カーソルは直前にいた項目の上に置かれます。

## 知っておくべきこと

- **一覧はスナップショットです。** 一覧から削除、移動、名前の変更をしたファイルは一覧から消えます。その後でツリーに追加されたファイルは、表示を抜けて開き直すまで現れません。
- **一覧からのコピーは平坦になります。** `2024/a.jpg` と `2025/a.jpg` を反対側のペインにコピーすると、両方ともそのディレクトリの直下に入るので、2 つ目は 1 つ目とぶつかり、いつもの[競合ダイアログ](FILE_OPERATIONS_FEATURE.ja.md)が表示されます。
- フラット表示はディレクトリで使います。検索結果のペインや取り込んだリストの上では、その旨を表示して何もしません。

## キーの変更

```python
KEY_BINDINGS['flat_view'] = ['Ctrl-B']
```

tmux の中では `Ctrl-B` は tmux のプレフィックスキーなので XeFM に届きません。tmux で使うときは別のキーを選んでください。[キーバインド](KEY_BINDINGS_FEATURE.ja.md)を参照してください。
