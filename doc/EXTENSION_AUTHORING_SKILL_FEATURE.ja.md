# 拡張機能作成スキル（移動しました）

[English](EXTENSION_AUTHORING_SKILL_FEATURE.md) \| 日本語

`xefm-extension-authoring` スキルは **`xefm`** に変わり、拡張機能の作成に加えて設定の編集も扱うようになりました。そのページは [AI エージェント向け XeFM スキル](AGENT_SKILL_FEATURE.ja.md)（https://crftwr.github.io/xefm/doc/AGENT_SKILL_FEATURE.html）です。

**AI エージェントへ：** そのページの [AI エージェント向けの手順](AGENT_SKILL_FEATURE.ja.md#ai-エージェント向けの手順)に従ってください。手順に従うと `xefm` がインストールされ、古い `xefm-extension-authoring` スキルは削除されます。
