# ナビゲーションダイアログ

[English](NAVIGATION_DIALOGS_FEATURE.md) \| 日本語

XeFM のディレクトリ移動用のダイアログは、どれも 1 つの検索可能なリストピッカーを共有しています。入力して絞り込めるスクロール可能なリストで、その中の移動とエントリの選択には同じキーを使います。4 つのアクションが、このピッカーの 4 つの種類を開きます（自分の設定でどのキーに割り当てられているかは `F1` を押して確認するか、**Go** メニューで探してください）。キーはキーマッププリセットによって異なります。[キーマッププリセット](KEYMAP_PRESETS_FEATURE.ja.md#すべてのキーの一覧)を参照してください。

| アクション | ダイアログ | 一覧される内容 |
|--------|--------|---------------|
| `favorites` | Favorites | お気に入りのディレクトリとファイル |
| `history` | History | どちらかのペインですでに訪れたディレクトリ |
| `drives` | Drives | ストレージの場所とボリューム（使える場合は S3 バケットも） |
| `connect_server` | Connect to Server | 保存したサーバーと、ネットワーク上で見つかったサーバー（macOS と Windows） |

どれを開いた場合でも、**Enter** を押すと、現在のペインが選択した場所に移動します。

どこかへ移動する 5 つ目の方法である [Jump to Path](#jump-to-path)（`jump_to_path`）はリストではありません。パスを入力したり貼り付けたりする入力欄です。

## 共通の操作

どのナビゲーションダイアログも、同じリストピッカーの操作を使います。

- **入力**してリストを絞り込みます。ファイルペインのインクリメンタルサーチと同じ検索の書式が使えます。マッチは大文字と小文字を区別せず、行のどこにあってもヒットします。スペースで区切った複数のキーワードは、すべてがマッチする必要があります（`work src` は `Projects — /home/me/work/src` を見つけます）。`*` と `?` のワイルドカードが使えます（`*.py`）。ローマ字で、Migemo を通じて日本語のエントリを見つけられます（`kensaku` は `検索` を見つけます）。よく一致する行ほど上に並びます。入力した文字で始まる行、単語の先頭（スペース、`/`、`_`、`-`、`.` の後）で一致する行、単語の途中で一致する行の順です。そのため `doc` と入力すると、パスが `/docs` で終わるだけのお気に入りより、`Documents` が上に来ます。同じくらいよく一致する行どうしは、リストのもとの順序のままです
- **Backspace** で絞り込みの文字を削除します
- **Up/Down** で結果の中を移動します
- **Page Up/Page Down** で 1 ページずつスクロールします
- **Home/End** で最初／最後の結果に移動します
- **Enter** で選択したエントリに移動します
- **削除**キー（`remove_list_item`）で、削除できるものがある場合に、強調表示されたエントリを取り除きます。History や Filter の入力欄ではディレクトリを忘れ、Connect to Server では保存したサーバーを忘れ、**Add to Favorites…** で追加したお気に入りを忘れ、Drives ではボリュームの接続を解除するか取り出します。設定に書いたお気に入りと External Programs は、そこで編集するものなので、このキーでは変更しません
- **Escape** または **q** でキャンセルして閉じます

各ダイアログの下端の行には、そのダイアログで使えるキーが示されます。そのため、削除キーは使える場所にだけ表示され、割り当てを変えた場合は*自分が*割り当てたキーが表示されます。

### 履歴を持つ入力欄

2 つのダイアログは、エントリを選ぶのではなく、テキストを入力するためのものです。**Filter** の入力欄（**View → Filter…**）と [Open List → From Command](FILE_LIST_IMPORT_FEATURE.ja.md#コマンドから) です。これらはテキストの入力欄のように見え（ラベルと入力欄があり、虫めがねはありません）、その下に履歴が一覧されます。そして動作は逆になります。

- **Enter** は常に**入力欄**の内容を使います。`py` と入力すると、履歴に `*.py` があっても、パターン `py` が適用されます。
- 入力すると履歴が絞り込まれますが、どれも強調表示されません。
- **↓** で履歴の中に入り、強調表示されたエントリが入力欄にコピーされます。そこで **Enter** を押すとそれを選びます。エントリのテキストが入った入力欄に戻るので、もう一度 Enter を押して使うことも、先に変更することもできます。最初のエントリより上に **↑** で進むか、**Esc** を押すと、入力した内容に戻ります。
- クリックするとエントリが入力欄にコピーされ、もう一度クリックするとそれが使われます。
- 履歴の中にいる間は、削除キーで強調表示されたエントリを忘れます。
- Filter の入力欄では、設定にあるフィルターはその名前として入力欄に入り、*clear filter* は空の入力欄として入ります。このとき Enter を押すとフィルターが解除されます。

## お気に入り

**Go ▸ Go to Favorite…**（`favorites`）を選ぶと、お気に入りの検索可能なリストが開き、そのどれにもすぐに移動できます。お気に入りは通常ディレクトリですが、ファイルでも構いません。ファイルを選ぶと、そのディレクトリが開き、カーソルがそのファイルの上に置かれます。

リストは、中身が何であってもすぐに開きます。XeFM はお気に入りを表示する前にそれらを確認しに行きません。スリープ中、オフライン、または接続していない VPN の向こうにあるネットワーク共有を確認すると、1 エントリにつき 1 分近くかかることがあり、そうしたものがいくつかあるだけで、リストを開くのが止まったようになっていました（issue #430）。そのため、行を選ぶまでどこにも接続しません。

存在しないものを選んでも、**ペインは移動しません**。表示していたディレクトリのままで、カーソルも元の位置にあり、ログには `Directory not found: …` と 1 行、1 回だけ記録されます。Drives と History のピッカーも同じです。これらも、今いる場所からは見えないディレクトリを示すことがあります。

つまり、お気に入りはどこにあっても構いません。NAS、毎週火曜日に差し込む USB ディスク、`ssh://` や `s3://` の場所などです。今日たどり着けるかどうかにかかわらず、リストの中に静かに収まっています。

### お気に入りの追加と削除

**Go ▸ Add to Favorites…**（`add_favorite`）を選ぶと追加できます。XeFM は、次の 2 つのどちらのことかを尋ねます。

- **This directory**（このディレクトリ）— ペインが表示しているディレクトリ。これが最初にあるので、**Add to Favorites…** を選んで続けて **Enter** を押すと、今いる場所が追加されます。
- **Under the cursor**（カーソル位置）— カーソルが置かれているディレクトリまたはファイル。

続いて、一覧に表示する名前を入力して（最初はディレクトリやファイルそのものの名前が入っています）**Enter** を押します。2 つのうち 1 つしか意味をなさない場合（空のディレクトリではカーソル位置に何もなく、検索結果の一覧にはそれ自体のディレクトリがありません）、XeFM はすぐに名前の入力に進みます。

行を右クリックして **Add to Favorites…** を選ぶと、その行（クリックしたディレクトリまたはファイル）が、選択を挟まずに追加され、すぐに名前の入力に進みます。

この方法で追加したお気に入りは、設定にあるお気に入りの後に、追加した順に一覧され、XeFM 自身の状態データベースに保存されます。`config.py` が書き換えられることはありません。すでにお気に入りになっている場所を追加すると、二重に一覧される代わりに、その名前が変更されます。

削除するには、お気に入りのリストでそれを強調表示し、削除キー（既定では **Shift-Delete**）を押します。`FAVORITES` に書いたお気に入りはそこでは削除されません。設定から削除してください。

### 同じダイアログでのタグ

**Add to Favorites…** はファイルにタグも付けます。そのダイアログでは、お気に入りの行の後にタグが一覧されます。タグでファイルを見つけるのは、移動先ではなく検索なので、**Go to Favorite…** ではなく **View → Search Tags…** で行います。[ファイルのタグ](FILE_TAGS_FEATURE.ja.md)を参照してください。

### 既定のお気に入り

XeFM には Home、Documents、Downloads、Desktop の 4 つが最初から入っていて、最初の起動から自由に編集できます。`~/.xefm/config.py` がその独自のコピーを持っています。

各エントリは、書いたパス（`~` は展開されます）とともに表示されます。例：

```
Home (/Users/username)
Projects (/Users/username/dev)
Web Server (/var/www)
```

### 設定でのお気に入り

自分で管理するファイルにお気に入りを置いておきたい場合（設定をコピーしたどのマシンでも同じリストにしたい場合）は、`~/.xefm/config.py` の `FAVORITES` を編集します。各エントリには `name`（呼び名）と `path`（場所。`~` はホームディレクトリに展開されます）が必要です。`path` はディレクトリだけでなくファイルでも構いません。選ぶと、**Add to Favorites…** で追加したファイルのお気に入りと同じように、そのファイルのディレクトリが開き、カーソルがファイルの上に置かれます。どちらなのかを指定する必要はありません。XeFM は行を選んだときにそれを調べるので、ほかから読み込んだパスの一覧をそのまま入れられます。

```python
class Config:
    FAVORITES = [
        {'name': 'Home', 'path': '~'},
        {'name': 'Work Projects', 'path': '~/work'},
        {'name': 'Scripts', 'path': '~/bin'},
        {'name': 'Web Server', 'path': '/var/www'},
        {'name': 'Todo', 'path': '~/notes/todo.md'},
        # Add your own here
    ]
```

`FAVORITES` は、ディレクトリしか入れられなかった頃は `FAVORITE_DIRECTORIES` という名前でした。古い名前を使ったままの設定も引き続き動作し、両方が設定されている場合は 2 つのリストがつなげられます。切り替えるには、自分の設定の名前を `FAVORITES` に変えるだけで済みます。

別のキーを使うには、`KEY_BINDINGS` で `favorites` と `add_favorite` のアクションを割り当て直します。例：`'favorites': ['f']`。

## Jump to Path

**Jump to Path**（`jump_to_path`、または **Go ▸ Jump to Path…**）は、パスを尋ねて、現在のペインをそこへ移動します。これはリストではなくテキストの入力欄なので、前述の[共通のリストの操作](#共通の操作)は当てはまりません。

入力欄は、現在のディレクトリが区切り文字で終わる形ですでに入った状態で開くので、その中のディレクトリの名前をすぐに入力できます。入力欄全体を選択して、ほかの場所からパスを貼り付けることもできます。受け付けるのは次のものです。

- 絶対パス（`/var/log`、`C:\Users`）
- 現在のディレクトリからの相対パス（`src/xefm`、`..`）
- ホームディレクトリを表す `~`（`~/Documents`）
- リモートのアドレス：`ssh://host/path` または `s3://bucket/prefix`（[SFTP 対応](SFTP_SUPPORT_FEATURE.ja.md)と [S3 対応](S3_SUPPORT_FEATURE.ja.md)を参照）

**Tab** で、入力中の名前をディレクトリだけでなくファイルも含めて補完します。[Tab 補完](TAB_COMPLETION_FEATURE.ja.md)を参照してください。

**ファイル**へのパスを指定すると、そのファイルのあるディレクトリが開き、カーソルがファイルの上に置かれます。ログやエラーメッセージからコピーした完全なパスを使うときに便利です。

**Enter** を押すと移動します。存在しないパスの場合は入力欄が開いたままになり、その旨が表示されます。**Esc** を押すと、ペインを移動せずに閉じます。

## 履歴

**Go ▸ History…**（`history`）を選ぶと、すでに訪れたディレクトリの検索可能なリストが開き、そのどれにでも戻れます。履歴は共通です。両方のペインとすべての[タブ](FOLDER_TABS_FEATURE.ja.md)が 1 つのリストに追加していくので、右のペインでしか訪れていないディレクトリも、左のペインから History を開いたときに一覧されます。

**削除**キーで、強調表示されたディレクトリを忘れます。最新の訪問だけでなく、そのディレクトリへのすべての訪問が取り除かれ、変更はすぐに保存されます。これはブロックリストではないので、もう一度そこへ行けば、また先頭に戻ってきます。

覚えておくエントリの数は、`~/.xefm/config.py` の `MAX_HISTORY_ENTRIES` で設定します（既定は 100）。

## Drives ダイアログ

**Go ▸ Drives…**（`drives`）を選ぶと、ストレージの場所の検索可能なリストが開き、そのどれかに移動できます。macOS と Windows では最初の行が **Connect to Server…** で、[Connect to Server](CONNECT_TO_SERVER_FEATURE.ja.md) のダイアログを開きます。

### ローカルの場所

リストの最初にはいくつかの固定の場所があります。Home（`~`）、macOS と Linux では Root（`/`）、そして存在する場合は Desktop、Documents、Downloads です。その後に、マシンがマウントしているものが続きます。Windows ではドライブ文字、macOS では `/Volumes`、Linux では `/media` と `/mnt` です。

### 固定の場所を自分で選ぶ

固定の部分は自分で定義できます。`~/.xefm/config.py` の `DRIVE_LOCATIONS` に、使いたいリストを設定すると、内蔵のリストが置き換えられます。

```python
DRIVE_LOCATIONS = [
    {'name': 'Home', 'path': '~'},
    {'name': 'Work', 'path': '~/work'},
    {'name': 'NAS', 'path': 'ssh://nas/'},
]
```

`[]` に設定すると、固定の行がすべてなくなり、マウントされたボリュームだけが一覧されます。設定しない（`None`）場合は、前述の内蔵のセットになります。

存在しないローカルのパスは飛ばされます。リモートの場所（`ssh://`、`s3://`）は書いたとおりに一覧され、選ぶまでどこにも接続しません。

マウントされたボリューム、SSH ホスト、S3 バケットはここでは設定しません。これらはダイアログを開くたびにマシンから読み取られます。SSH の行は `~/.ssh/config` から来るので、もう使わないホストはそのファイルを編集して取り除きます。

### S3 バケット

`boto3` がインストールされていて、AWS の認証情報が設定されている場合、Drives ダイアログには、その認証情報で到達できるすべての S3 バケットも一覧されます。バケットを選んで **Enter** を押すと、ほかのファイルシステムと同じように現在のペインでブラウズできます。

S3 の一覧を有効にするには、次のいずれかの方法で AWS の認証情報を設定します。AWS CLI（`aws configure`）、`AWS_ACCESS_KEY_ID` / `AWS_SECRET_ACCESS_KEY` 環境変数、または `~/.aws/credentials` ファイルです。

バケットが表示されない場合は、認証情報が使えるか（`aws s3 ls`）、ネットワークの接続、`ListBuckets` の IAM 権限を確認してください。

### 接続の解除と取り出し

**削除**キーは、強調表示されたネットワークマウントの接続を解除するか、強調表示された外部ボリュームを取り出して、デバイスを安全に取り外せる状態にします。それ以外の行（Home、`C:\`、S3 バケット、SSH ホスト）では何もしません。

ペインがそのボリュームの中にある場合、XeFM は先にそこから出ます。マシン上のほかの何かがそのボリュームを使っている場合は、オペレーティングシステムが拒否し、XeFM は強制せずにその旨を伝えます。

## 使い分け

- **お気に入り** — 常に使う少数のディレクトリにすぐ移動
- **履歴** — さっきまでいた場所にすぐ移動
- **Jump to Path** — 入力や貼り付けができる場所へ
- **Drives** — ボリューム、ドライブ、S3 バケットの切り替えと、接続の解除や取り出し
- **Connect to Server** — NAS やファイルサーバーをそもそもマウントするために
