# Markdown ビューアー

[English](MARKDOWN_VIEWER_FEATURE.md) \| 日本語

XeFM の内蔵ファイルビューアーは、いつもの行番号付きの生テキスト表示に加えて、Markdown ファイル（`*.md`、`*.markdown`）を整形されたリッチテキストとして表示できます。見出し、**太字** / *斜体*、`code`、リスト、表、引用、リンク、画像を表示します。

## ファイルを開く

Markdown ファイル（または任意のテキストファイル）で **V** を押すと、ビューアーが開きます。最初に表示されるのは**生テキスト**表示（行番号、シンタックスハイライト、インクリメンタルサーチ、行の折り返し）です。ただし、この種類のファイルでは整形表示を使いたいと XeFM に伝えてある場合は別です（後述の*選択を覚える*を参照）。

## 整形表示への切り替え

ファイルに整形表示がある場合（現時点では Markdown）、**M** を押すと次の 2 つを切り替えられます。

- **生テキスト** — 行番号と検索が使えるソース。
- **整形表示** — 整形されたドキュメント。

もう一度 **M** を押すと元に戻ります。2 つの表示は独立していて、それぞれがどこまでスクロールしたかを覚えているので、行き来してもそれぞれの表示で元の位置に戻れます。

## 選択を覚える

XeFM は、最後に選んだ表示を**ファイルの種類ごとに**覚えていて、次にその種類のファイルを開くときも同じ表示で開きます。`.md` ファイルを整形表示に切り替えると、それ以降に開く `.md` ファイルは（このセッションでも再起動後でも）すべて整形表示で開きます。1 つを生テキストに戻すと、`.md` ファイルはまた生テキストで開くようになります。この設定は拡張子ごとに別々に記録され、実際に整形表示がある種類のファイルだけが対象です（`.txt` や `.py` は覚えることが何もないので、常に生テキストで開きます）。

フッターには表示を切り替えるキーが、ヘッダーの右上には現在の表示が示されます（生テキストでは行の位置、整形表示ではレンダラーの名前、たとえば *Markdown*）。

整形表示のないファイル（`.txt`、`.py` など）には切り替える先がないので、**M** を押しても何も起きません。

## 整形表示での移動

| キー | アクション |
|-----|--------|
| ↑ / ↓ | 1 行スクロール |
| PgUp / PgDn | 1 ページスクロール |
| Home / End | 先頭／末尾に移動 |
| マウスホイール | スクロール |
| **F** | インクリメンタルサーチ |
| **M** | 生テキストに戻る |
| **F1** | キーのヘルプ |
| **Q** / Esc | ビューアーを閉じる |

### 整形表示での検索

インクリメンタルサーチ（**F**）は、生テキストだけでなく整形表示でも使えます。**F** を押してパターンを入力すると、整形されたドキュメントの中で、すべての出現箇所がその表示位置で強調表示されます。装飾されたテキスト（見出し、**太字**の部分、インラインの `code`、リンク）の中のマッチは、強調表示の下でもそれぞれの色を保ちます。**↑** / **↓** で前／次のマッチに移動し、**Enter** で現在の位置のまま確定し、**Esc** でキャンセルして元の位置に戻ります。マッチは大文字と小文字を区別せず、フッターのカウンターには*現在の位置 / 総数*が表示されます。

行の折り返し（**W**）は、引き続き生テキスト表示にだけ適用されます（整形表示のドキュメントは、もともと文章をペインの幅で折り返しています）。

## 注意

- 整形表示は現在のテーマに従い、ターミナルとネイティブ（macOS / Windows）のバックエンドの両方で動作します。ターミナルでは見出しや強調は太字／斜体で表示され、グラフィカルなバックエンドでは本来のサイズのプロポーショナルフォントで表示され、本物の表や画像も表示されます。
- ほかの種類のファイルにも整形表示があり、同じ **M** で切り替えられます。JSON / JSON Lines と CSV / TSV です。[JSON と CSV のビューアー](JSON_CSV_VIEWERS_FEATURE.ja.md)を参照してください。
