# ヘルプダイアログ（F1 キー）

[English](HELP_DIALOG_FEATURE.md) \| 日本語

XeFM には、画面に表示されているもののキーバインドを一覧するスクロール可能なヘルプダイアログがあります。ファイル一覧で **F1** を押すと、ここで説明するダイアログが開きます。ビューアー（テキスト、画像、ファイルの差分、ディレクトリの差分）も **F1** に応答しますが、それぞれこのダイアログではなく独自のキー一覧を表示します。

## 使い方

- **F1** — ヘルプダイアログを開きます
- **↑/↓** — 1 行ずつスクロールします（マウスホイールでもスクロールできます）
- **Page Up/Down** — 1 ページずつスクロールします
- **Home/End** — 先頭／末尾へ移動します
- **Tab / Shift-Tab** — 次／前のリンクへ移動します
- **Enter** — 移動先のリンクを開きます。リンクがなければダイアログを閉じます
- **Escape** — 閉じます（ダイアログの外をクリックしても閉じます）

## アクションの詳細

1 行の説明では書ききれないことがあるアクション（何が必要か、選択項目をどう扱うか、何を受け付けないか）は、ダイアログ内の説明がリンクになっています。クリックするか、Tab で移動して Enter を押すと、そのアクションについてのページがヘルプの上に開きます。内容は、何をするか、キー、選択項目が必要かどうかです。**Escape** を押すと、離れたところのままヘルプに戻ります。自分で書いたアクションも、docstring に 1 行目より多くの内容があればページを持ちます。

[コマンドパレット](COMMAND_PALETTE_FEATURE.ja.md)でも、行の上で F1 を押すと同じページが開きます。

## 内容

ヘルプは現在のキーバインドから生成されるので、カスタマイズも含めて常に自分の設定を反映しています。各行にはキーとその動作が表示され、その後にアクション名が続きます（`Move cursor up · cursor_up`）。この名前はキーを割り当て直すときに `KEY_BINDINGS` に書くものなので、ここで調べられます。下の一覧がキーを挙げずに各セクションの内容を説明しているのもそのためです。*自分の* 環境でどのキーが何をするかは、ダイアログそのもので確認してください。

アクティブなペインに追加の情報の印（タグの点、Git の状態など）が表示されていると、ヘルプは **Markers in this pane** の節から始まります。このタブで有効な追加の情報についてだけ、印ごとにその色と意味が並びます（[ファイルリストのレイアウト](FILE_LIST_LAYOUTS_FEATURE.ja.md)を参照）。キーのセクションはその後に次の順で並びます。

- **Navigation** — カーソルの移動、項目を開く、親ディレクトリやルートへの移動、ペインの切り替え、移動用ダイアログ（お気に入り、履歴、ドライブ、入力したパス、反対側のペインのディレクトリ）
- **Selection** — 項目を 1 つずつ、またはまとめて選択する操作、選択の解除、選択項目の間の移動、反対側のペインとの比較
- **File Operations** — 作成、名前の変更、コピー、移動、削除、アーカイブの作成と展開、ファイルの詳細、編集、名前やパスのクリップボードへのコピー、選択項目を OS・外部プログラム・シェルに渡す操作
- **Search** — インクリメンタルサーチ、ファイル名のフィルター、再帰的なファイル名検索と内容検索（grep）、および検索ダイアログ自体のオプション（大文字・小文字、パターンの構文、サブフォルダー）
- **Incremental Search (while the search bar is open)** — 検索バーが開いている間に検索バー自体が応答するキー：一致箇所の間の移動、一致項目の選択、確定、キャンセル
- **View** — テキストビューアー、2 つのファイルの比較、隠しファイル、カラーテーマ、ソート（ソートダイアログとクイックソート）
- **Log Pane** — ログのスクロール、サイズ変更、ログからのコピー
- **Other** — メニューバー、設定の編集と再読み込み、ヘルプ、終了
- **Your Actions (config.py)** — 自分の設定で定義したアクション。それぞれの docstring の 1 行目とともに一覧表示されます。設定でアクションを 1 つも定義していなければ表示されません（[カスタマイズ](CUSTOMIZATION_FEATURE.ja.md)を参照）
- **Archive Formats** — この XeFM でブラウズ、展開、作成できるアーカイブ形式と、見つかった libarchive。一覧はインストールされているものによって変わるため、あらかじめ書かれているのではなく XeFM の起動時に作られます（[アーカイブ](ARCHIVE_FEATURE.ja.md)を参照）

いくつかの行は、それが機能する環境でだけ表示されます。ターミナル版はウィンドウ内のメニューバーを一覧に含めます。デスクトップ版ではメニューバーが OS 自身のものなので、一覧には含めません。

設定でキーが割り当てられていないアクションは、キーの代わりにダッシュ（—）を表示し、その後にそのアクションを実行できるメニューを表示します。便利なアクションのいくつかは意図的にキーを割り当てずに提供しているので、キーを割り当てるまではメニューから実行します。

使い方のヒントはここには *ありません*。それらは別の Tip of the Day ダイアログ（Help → Tip of the Day…）にあり、[ヒント](TIPS_FEATURE.ja.md)で説明しています。

## 設定

ヘルプは既定で **F1** に割り当てられています。別のキーを使うには、`KEY_BINDINGS` で `help` アクションを割り当て直します。

```python
KEY_BINDINGS = {
    'help': ['F1', 'H'],  # F1 or H shows help
    # ... other bindings
}
```

## About ダイアログ

ヘルプダイアログとは別に、**About** ダイアログには XeFM の名前、バージョン番号、クリックできるリンクとして GitHub リポジトリの URL が表示されます。どのプラットフォームでも、メニューバーの **Help → About XeFM** から開けます。

OK ボタンを押すか、Enter、Space、ESC のいずれかを押すと閉じます。テキスト効果を持つカラーテーマ（Sci-Fi）では、ボックスが開くと同時にテキストが解読されるように現れます。ほかのテーマでは単に表示されます。
