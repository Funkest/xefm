# フォルダータブ

[English](FOLDER_TABS_FEATURE.md) \| 日本語

各ペインは複数の**タブ**を持つことができ、タブはそれぞれ自分の場所を開いたまま保ちます。作業中に行き来する数個のディレクトリに使ったり、別の場所をブラウズしている間に検索結果や読み込んだ一覧を残しておいたりするのに使います。

| アクション | キー | メニュー |
|--------|-----|------|
| `new_tab` | `T` | Go → New Tab |
| `open_in_new_tab` | `Shift-T` | Go → Open in New Tab |
| `close_tab` | `Ctrl-W` | Go → Close Tab |
| `next_tab` | `Ctrl-PageDown` | Go → Next Tab |
| `prev_tab` | `Ctrl-PageUp` | Go → Previous Tab |

どれも**アクティブなペイン**に対して働きます。左右のペインはそれぞれ別のタブを持ちます。

## 開くと閉じる

- **New Tab** は、現在のタブと同じ場所を表示し、カーソルも同じ項目にあるタブを開いて、そのタブに切り替えます。検索結果や一覧の上で使うと、新しいタブにはその一覧のディレクトリが表示され、結果は元のタブに残ります。
- **Open in New Tab** は、カーソル位置のディレクトリを新しいタブで開きます。現在のタブはその場所のままです。
- **Close Tab** は現在のタブを閉じ、次のタブを表示します。ペインの最後のタブは閉じられません。
- **Next / Previous Tab** は、どちらの端でも反対の端に回り込みます。

## タブバー

ペインのタブが 2 つ以上になると、パスの上にタブバーが現れます。

```
 1 src   2 docs   3 ⌕ TODO
 ~/projects/xefm/doc
```

現在のタブは強調表示されます。タブをクリックするとそのタブに切り替わります。タブが 1 つのペインにはタブバーが表示されないので、ターミナルで余分な場所を取りません。

各ラベルはディレクトリの名前です。検索は `⌕ query`、読み込んだ一覧は `[title]` と表示されます。全部が収まらないときはラベルが短縮されます。

## タブが保持するもの

ペインに表示されているものすべてです。ディレクトリ、カーソル、選択、ソート、フィルターを保持します。検索結果、読み込んだ一覧、ブランチ表示はそのまま保持されるので、いったん離れてあとで戻ってくることができます。

ディレクトリのタブは、切り替えて戻ったときに読み直されます。隠れている間に変わったもの（反対側のペインから加えた変更も含む）は、ちらつきなしに反映されます。

**履歴は共有されます。** `H` は、どのタブで訪れたディレクトリも一覧表示します。

## セッションをまたいで

終了時に、XeFM は各ペインのタブ（ディレクトリ、ソート、フィルター）と、どのタブが現在のタブだったかを保存します。次回の起動時には、現在のタブだけが読み込まれます。他のタブは初めて切り替えたときに読み込まれるので、リモートサーバー上のタブが起動時に接続することはありません。

検索結果や一覧のタブは、そのディレクトリとして復元されます。コマンドラインでディレクトリを指定して開いたペインは、その 1 つのタブだけで始まります。

## キーを変更する

```python
KEY_BINDINGS['next_tab'] = ['Ctrl-PAGE_DOWN', 'Ctrl-TAB']
KEY_BINDINGS['prev_tab'] = ['Ctrl-PAGE_UP', 'Ctrl-Shift-TAB']
```

ターミナルは `Ctrl-Tab` を送らないため、これは既定になっていません。デスクトップアプリしか使わない場合は自分で追加してください。[キーバインド](KEY_BINDINGS_FEATURE.ja.md)を参照してください。
