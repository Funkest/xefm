# OS のインデックスを検索

[English](OS_INDEX_SEARCH_FEATURE.md) \| 日本語

オペレーティングシステムは、ファイルの名前や内容をはじめ、ファイルに関するさまざまな情報のインデックスをすでに持っています。macOS では **Spotlight**、Windows では **Windows Search** です。XeFM はそのインデックスを検索し、見つかったものを一覧として表示できます。その一覧の中でソート、フィルター、コピー、移動、削除ができます。

| アクション | メニュー |
|--------|------|
| `index_search` | View → Search Spotlight…（macOS）／ Search Windows Search…（Windows） |

キーはキーマッププリセットによって異なります。[キーマッププリセット](KEYMAP_PRESETS_FEATURE.ja.md#すべてのキーの一覧)を参照してください。

**検索ダイアログ**がインデックスモードで開きます。Search Files と Search Content に並ぶモードで、`Tab` で 3 つを切り替えます。結果は**入力するそばから**表示され、`Enter` を押すとそれらすべてがペインに一覧として開き、カーソルはそれまでいた行に置かれます。

検索するのは**アクティブなペインのフォルダーとその下のすべて**です。ホームフォルダー全体を検索するには、そこから実行してください。

これは macOS と Windows 向けの機能です。Linux では、[Open List from Command](FILE_LIST_IMPORT_FEATURE.ja.md) で各インデクサー付属のツール（`plocate`、`baloosearch`、`recollq`）を使ってください。

## 構文を使わずに：フィルターチップ

ステータス行の右側にあるチップで、どの検索も絞り込めます。**Kind**（フォルダー、ドキュメント、画像、動画、音声、アーカイブ）、**Date**（今日、過去 7 日または 30 日、今年に更新）、**Size**（1 MB、100 MB、1 GB 以上）です。クリックして値を選びます。チップは入力した内容と組み合わせられ、何も入力しなければチップだけで検索します。Kind を **Images**、Date を **Past 7 days** にすると、このフォルダーの下で今週変更されたすべての画像が見つかります。[検索オプション](SEARCH_OPTIONS_FEATURE.ja.md#フィルターチップ)を参照してください。

## クエリの書き方

クエリは、その OS 自身の検索が解釈する書き方で書きます。

**macOS（Spotlight）では**、Spotlight の検索欄と同じです。

| クエリ | 見つかるもの |
|-------|-------|
| `budget 2026` | 名前または内容に両方の単語を含むファイル |
| `name:report` | 名前に「report」を含むファイル |
| `kind:pdf` | PDF ドキュメント（`kind:image`、`kind:movie`、`kind:folder` なども可） |
| `kMDItemPixelWidth > 4000` | 幅が 4000 ピクセルを超える画像 |
| `kMDItemDurationSeconds > 600` | 10 分より長い音声と動画 |
| `kMDItemWhereFroms == "*example.com*"` | あるサイトからダウンロードしたファイル |
| `kMDItemLastUsedDate > $time.today(-7)` | この 1 週間に開いたファイル |

**Windows（Windows Search）では**：

| クエリ | 見つかるもの |
|-------|-------|
| `budget 2026` | 名前または内容に両方の単語を含むファイル |
| `where System.Size > 100000000` | Windows Search の SQL 条件をそのまま書いたもの。この例では 100 MB を超えるファイル |
| `where System.Kind = 'picture'` | 画像 |

以前に実行したクエリは検索欄から呼び出せます。右端の `▾` をクリックするか `Alt-↓` を押して選びます。`Shift-Delete` でハイライトされたものを履歴から消します。

## 検索結果

一致したものは、クエリをタイトルにした一覧としてアクティブなペインに開きます。一覧のすべての機能が使えます。日付やサイズでのソート、フィルター、選択、コピー、移動、表示、そして `sync_other_to_current` でファイルの実際の場所を開くこともできます。`Backspace` でフォルダーに戻ります。

インデックスに問い合わせられない場合は、ダイアログのステータス行に理由が表示されます。

## Finder の保存済み検索

Finder の **Smart Folder**（スマートフォルダー）は `.savedSearch` ファイルで、通常は `~/Library/Saved Searches` にあります。XeFM でこのファイルの上で `Enter` を押すと、保存時のフォルダーでそのクエリが実行され、一致したものがそのファイルの名前を付けた一覧として表示されます。Finder で作った検索が、ここではキー 1 つで開ける一覧になります。

## 知っておきたいこと

- **何が見つかるかはインデックスで決まります。** Spotlight は、システム設定 → Spotlight → 検索のプライバシーに登録されたフォルダーを対象外にします。Windows Search の既定の対象はユーザーフォルダーとライブラリで、ドライブ全体ではありません。また、このサービスは無効にできます。インデックスの外にあるファイルは見つかりません。その場合は、フォルダーを自分でたどる **View → Search Files…** を使ってください。
- **ローカルフォルダーのみです。** マウントしたネットワーク共有は、OS がインデックスを作っている場合にだけ検索されます。`ssh://` と `s3://` のフォルダーは対象外です。
- **Windows** では `comtypes`（XeFM と一緒にインストールされます）が必要です。見つからない場合は、アクションがインストール方法を表示します。
