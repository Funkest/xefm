# The Extension Authoring Skill (moved)

The `xefm-extension-authoring` skill is now **`xefm`**, and it covers editing
your configuration as well as writing extensions. Its page is
[The XeFM Skill for AI Agents](AGENT_SKILL_FEATURE.md)
(https://crftwr.github.io/xefm/doc/AGENT_SKILL_FEATURE.html).

**AI agents:** follow the
[Instructions for AI agents](AGENT_SKILL_FEATURE.md#instructions-for-ai-agents)
on that page. They install `xefm` and remove the old `xefm-extension-authoring`
skill.
