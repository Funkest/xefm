# 2 画面でのファイル管理

[English](DUAL_PANE_FEATURE.md) \| 日本語

XeFM は 2 つのディレクトリを並べて表示するので、その間でのコピー、移動、比較が 1 画面のファイルマネージャーよりずっと素早く行えます。一方のペインが**アクティブ**（強調表示され、カーソルがある）で、もう一方は非アクティブです。**Tab** を押すと、アクティブなペインが切り替わります。

それぞれのペインは、現在のディレクトリ、カーソル位置、選択項目、ソートモード、フィルター、履歴を別々に持っており、完全に独立しています。

## アクション

これらがどのキーに割り当てられているかは、XeFM で `F1` を押すと確認できます。ヘルプは自分の `KEY_BINDINGS` から作られるので、常に自分の設定どおりの内容です。

| アクション | 動作 |
|--------|--------------|
| `switch_pane` | アクティブなペインを切り替えます |
| `focus_left` / `focus_right` | そのペインにフォーカスを移します。既定ではキーに割り当てられていません |
| `sync_current_to_other` | 現在のペインのディレクトリを反対側のペインに揃えます |
| `sync_other_to_current` | 反対側のペインのディレクトリを現在のペインに揃えます |
| `copy_files` | 選択したファイルを反対側のペインのディレクトリにコピーします |
| `move_files` | 選択したファイルを反対側のペインのディレクトリに移動します |
| `copy_files_to` / `move_files_to` | 選択したファイルを、入力したディレクトリにコピー／移動します（反対側のペインのディレクトリが入力済み） |
| `compare_selection` | ペイン間でファイル／ディレクトリを比較します |
| `adjust_pane_left` | ペインの境界を左に動かします（左のペインが狭くなります） |
| `adjust_pane_right` | ペインの境界を右に動かします（左のペインが広くなります） |

コピー／移動の行き先は常に*反対側の*ペインです。そのため、よくある手順は、それぞれのペインでディレクトリを開き、一方で選択して、操作する、というものです。

## 使い方のヒント

2 つのペインが本当に役立つのは、次のような使い方です。

- **ディレクトリ間でのコピー／移動** — 一方のペインでコピー元を、もう一方でコピー先を開き、ファイルを選択してから反対側へコピーまたは移動します。
- **2 つのディレクトリの比較** — 両方のペインで関連するディレクトリを開いて `compare_selection` を実行すると、それぞれのペインにしかないファイル（または両方にあるファイル）が一覧されます。そこからコピー／移動して両者を揃えます。
- **バックアップ** — 左にコピー元、右にバックアップ先を開き、`toggle_select_files` ですべてのファイルを選択して反対側へコピーします。
- **1 つのディレクトリを両側から扱う** — `sync_current_to_other` は現在のディレクトリを反対側のペインにも開きます。大きなディレクトリで、一方の表示で選択しながら、もう一方で別の部分をスクロールしたいときに便利です。
- **アーカイブのブラウズ** — 一方のペインでアーカイブ（`archive://...`）の中に入り、もう一方のペインの通常のファイルシステムへファイルをコピーして取り出します。
- **S3 との転送** — 一方のペインでローカルのファイルシステム、もう一方で S3 バケット（`s3://...`）を開き、ローカルとクラウドストレージの間でコピーします。

## ペインの幅

左右の境界は **[**（左のペインを狭く）と **]**（左のペインを広く）で調整できます。比率は保存され、再起動しても復元されます。起動時の既定値は `~/.xefm/config.py` で設定します。

```python
DEFAULT_LEFT_PANE_RATIO = 0.5  # 50/50 (default); 0.6 = wider left, 0.4 = wider right
```

## 状態の保存

XeFM は、それぞれのペインの現在のディレクトリとカーソル位置、ペインの比率、どちらのペインがアクティブだったかを `~/.xefm/state.json` に保存し、次回のセッションでも覚えています。

## コマンドライン引数

XeFM を起動するときに、それぞれのペインの開始ディレクトリを指定できます。

```bash
# Left pane only
python3 -m xefm --left /path/to/directory

# Right pane only
python3 -m xefm --right /path/to/directory

# Both panes
python3 -m xefm --left ~/documents --right ~/downloads
```
