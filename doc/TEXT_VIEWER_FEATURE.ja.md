# テキストビューアー

[English](TEXT_VIEWER_FEATURE.md) \| 日本語

XeFM には、ソースコード、設定ファイル、ログ、その他あらゆるテキストのためのテキストビューアーが内蔵されています。エンコーディングは自動的に検出されます。BOM の有無を問わない UTF-8、Shift-JIS、EUC-JP、ISO-2022-JP、Latin-1 / CP1252 などに対応し、`change_encoding` で手動で指定することもできます（[テキストエンコーディング](TEXT_ENCODING_FEATURE.ja.md)を参照）。ファイルにカーソルを合わせて `view_file` を実行する（または、他に `enter` のルールがないファイルで `open_item` を実行する）と、XeFM を離れずにウィンドウ全体に開きます。バイナリファイルは検出され、文字化けの代わりに短いプレースホルダーが表示されます。

よりリッチな表示ができるファイル形式（特に Markdown）では、ビューアーは描画された表示とプレーンなソースを切り替えられます（下記と[Markdown ビューアー](MARKDOWN_VIEWER_FEATURE.ja.md)を参照）。

## 開き方と操作

ビューアーは下端に自分のキーを表示し、ビューアー内で `F1` を押すとすべてのキーが一覧表示されます。どちらも `KEY_BINDINGS` から読み取るので、どう割り当てていても正しく表示されます。

| アクション | 動作 |
|--------|--------------|
| `view_file` | フォーカスのあるファイルをテキストビューアーで表示 |
| `open_item` | 同上。他に `enter` のルールがないファイルの場合 |
| `↑` `↓` `PgUp` `PgDn` `Home` `End` | 1 行、1 ページ、または先頭／末尾までスクロール（Vim style には独自のスクロールキーもあります） |
| `←` `→` | 横スクロール（行の折り返しがオフのとき） |
| `toggle_wrap` | 行の折り返しを切り替え |
| `isearch` | インクリメンタルサーチ。その後 `↑` / `↓` で一致箇所を移動 |
| `toggle_view_mode` | 整形表示／生テキスト表示を切り替え（Markdown などのリッチな形式） |
| `change_encoding` | テキストのエンコーディングを選択（Auto／明示的な指定） |
| `edit_file` | 表示中のファイルを設定したエディターで編集 |
| `Cmd`/`Ctrl` + `C` | 現在の選択範囲をコピー |
| `Cmd`/`Ctrl` + `A` | ファイル全体を選択 |
| `F1` | キーのヘルプ |
| `quit` / `Esc` | ビューアーを閉じる |

`isearch`、`edit_file`、`quit` のキーと、Vim style の追加のスクロールキーは、キーマッププリセットによって異なります。[キーマッププリセット](KEYMAP_PRESETS_FEATURE.ja.md#すべてのキーの一覧)を参照してください。

固定の `Esc` とコピー／すべて選択のキーを除き、ここにあるキーはすべてアクションで、設定の `KEY_BINDINGS` で割り当て直せます。スクロールキーもアクションです（`text_viewer.scroll_up`／`scroll_down`、`text_viewer.page_up`／`page_down`、`text_viewer.scroll_top`／`scroll_bottom`、`text_viewer.scroll_left`／`scroll_right`）。`KEY_BINDINGS` に書かなければ、矢印、ページ、Home、End のキーのままです。

## タブとシンタックスハイライト

- **タブ**は自動的にスペースに展開され、8 桁ごとのタブ位置に揃えられます。展開は桁を考慮して行われるので、全角文字（CJK や絵文字）があっても揃います。
- **シンタックスハイライト**は、[Pygments](https://pygments.org/) がインストールされていれば自動的に適用されます。言語はファイルの拡張子から選ばれます。Pygments がなくてもテキストは表示され、色が付かないだけです。シンタックスの色はアクティブなテーマに従います。Pygments が知らない言語や、間違った言語に割り当てられてしまう拡張子については、`config.py` の [`LEXERS`](CUSTOMIZATION_FEATURE.ja.md#自分のシンタックスハイライトlexerspreview) で自分でレキサーを指定してください。
- **行の折り返し**は既定でオフです（そのため長い行は `←` / `→` で横スクロールします）。`W` を押すと代わりに折り返します。フッターに `WRAP` 表示が出ます。

## テキストの選択とコピー

マウスでテキストを選択し、クリップボードにコピーできます。

| 操作 | 選択されるもの |
|---------|---------|
| クリックしてドラッグ | 押した位置から離した位置までの任意の範囲 |
| ダブルクリック | ポインター位置の単語全体 |
| トリプルクリック | ポインター位置の行全体 |
| ダブルクリック／トリプルクリックのあとドラッグ | 単語／行単位で広げる |
| Shift-クリック | 現在の選択範囲をクリックした位置まで広げる |
| `Cmd`/`Ctrl` + `A` | ドキュメント全体を選択 |

ドラッグ中は強調表示される範囲がポインターに追従し、選択はスクロールしても保たれます。スクロールして離れてから戻っても、選択はそのまま残っています。

1 画面より多く選択するには、テキストの上端か下端を越えてドラッグし、そのまま保ちます。ポインターの下で表示がスクロールし続け、それに合わせて選択が広がります。外側に離れているほど速くスクロールします。内側に戻すか、ボタンを離すと止まります。

コピーするには `Cmd`+`C`（macOS）または `Ctrl`+`C`（Linux / Windows）を押します。テキストビューアーは選択したソーステキストを正確にコピーし、表示上の各行がそれぞれ 1 行になります。

### ターミナルでは

コピーが**システムの**クリップボードに届くかどうかは、ターミナルが OSC 52 のクリップボード用エスケープシーケンスに対応しているかどうかによります（最近のほとんどのターミナルは対応しています）。XeFM の中で貼り付ける分には、どの場合でもコピーは機能します。

### Markdown 表示からのリッチコピー

**描画された Markdown** の表示（`.md` ファイルで `toggle_view_mode`）からコピーすると、書式付きでコピーされます。書式に対応したアプリに貼り付けると、太字、斜体、インラインコード、リンク、見出し、表がそのまま再現され、プレーンなエディターにはプレーンテキストが貼り付けられます。詳しくは [Markdown ビューアー](MARKDOWN_VIEWER_FEATURE.ja.md)を参照してください。
