# ドキュメントをテキストとして表示

[English](DOCUMENT_VIEWER_FEATURE.md) \| 日本語

XeFM のビューアーは **ドキュメントに書かれている内容** を表示します。PDF、Word、Excel、PowerPoint、OpenDocument、EPUB ファイルのテキストを、見出し、リスト、表、ページ、スライド、シートとともに表示します。サーバー上やアーカイブ内のファイルでも、検索、選択とコピー、ウィンドウ幅での折り返しができます。

| ファイル | |
|---|---|
| PDF `.pdf` | 各ページのテキスト |
| Word `.docx`、OpenDocument `.odt` | 見出し、段落、リスト、表、ページのヘッダーとフッター |
| Excel `.xlsx`、OpenDocument `.ods` | シートごとに 1 つの表 |
| PowerPoint `.pptx`、OpenDocument `.odp` | スライドごとに 1 つのセクション。タイトル、箇条書き、表、**スピーカーノート** を含みます |
| EPUB `.epub` | 章ごとに 1 つのセクション |

古い Office 形式（`.doc`、`.xls`、`.ppt`）は読み込みません。これまでどおり、それぞれのアプリケーションで開きます。

## 開く

ファイル上で `Enter` を押すか **File → View File**（ファイルを表示、`view_file`）を選ぶと、ビューアーで開きます。大きなドキュメントやリモートのドキュメントは、読み込み中にまず進捗ダイアログが表示されます。`Esc` で読み込みを中止します。

Markdown ファイルと同じく、ビューアーには 2 つのモードがあります。`M`（`toggle_view_mode`）で切り替えられ、XeFM はファイルの種類ごとに選択を記憶します。

- **Rendered**（整形表示、初回）：見出し、リスト、表、そしてページ・スライド・シート・章ごとの見出し。
- **Text**（テキスト表示）：検索が見るのと同じプレーンテキストを、1 行ずつ。

検索（`isearch`）、選択、コピーはどちらのモードでも使えます。ヘッダーにはドキュメントの種類とサイズが表示されます（例："PowerPoint · 12 slides"）。

## 表示されるもの、されないもの

ビューアーが表示するのはテキストで、ページそのものではありません。レイアウト、フォント、画像、グラフは描画されません。ドキュメントの見た目を確認するには、**File → Open with Default App**（既定のアプリで開く、`open_with_os`）でそのアプリケーションで開いてください。

- **スキャンした PDF** にはテキストがなく、各ページの画像しかありません。ビューアーは空のページを表示する代わりに、その旨を表示します。XeFM は OCR を行いません。
- **パスワードで保護された PDF** は開きません。ビューアーはその旨を表示します。アプリケーションでなら開けます。
- **PDF** は各ページのテキストを読む順に表示します。PDF は見出しや表をそれとして記録していないため、見出しや表は表示されません。
- **スプレッドシートのセル** には、セルが保持する値が表示されます。日付は、Excel がその日付を格納している数値として表示されます。

## ドキュメント内を検索する

**View → Search Content…**（`find_in_files`）は、これらのドキュメントを同じテキストを通して読み込みます。そのため、PDF やスライドの中の単語も、テキストファイルの中の単語と同じように見つかります。各ヒットには、抽出されたテキストの該当行が表示されます。

## 表示で Preview や Word が開いてしまう場合

XeFM に同梱の設定では、これらのファイル上の `view_file` は内蔵ビューアーに送られます。この機能より前に作成された `config.py` は異なる指定のままで、そちらが優先されます。`FILE_ASSOCIATIONS` の PDF と Office のエントリの `'view'` を `None` に変更してください。

```python
{
    'pattern': '*.pdf',
    'open': ['open', '-a', 'Preview'],
    'view': None,           # V: XeFM's own viewer
    'edit': None,
},
```

`Enter` は `'view'` の指定にかかわらず、すでに内蔵ビューアーを使います。

キーはキーマッププリセットによって異なります。[キーマッププリセット](KEYMAP_PRESETS_FEATURE.ja.md#すべてのキーの一覧)を参照してください。

## 動作要件

ドキュメントの読み込みには [doc-files](https://github.com/crftwr/doc-files) を使い、PDF には [pypdf](https://pypi.org/project/pypdf/) を使います。どちらも XeFM に同梱されています。
